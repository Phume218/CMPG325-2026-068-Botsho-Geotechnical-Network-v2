# Milestone 2 – Network Implementation and Testing

This folder contains the implementation, configuration, testing and verification evidence for the Botsho Geotechnical Engineers network developed in Cisco Packet Tracer.

## Milestone 2 Evidence

The evidence covers:

- Cisco Packet Tracer network implementation
- VLAN configuration and network segmentation
- Router-on-a-stick inter-VLAN routing
- Scoped multi-VLAN DHCP configuration
- DHCP client address assignment and verification
- CR8 shared printer zone implementation
- End-to-end connectivity testing
- Configuration verification
- Troubleshooting and validation
- Final technical documentation

## Assigned Networking Challenge

**DHCP – Scoped Multi-VLAN Address Assignment**

Separate DHCP scopes were implemented for the Engineering and Administration networks. DHCP operation was verified using router DHCP pool and binding information together with client IP configuration.

## Client Change Request – CR8

A shared printer zone was implemented to provide printer connectivity to the required departments. The shared printer uses IP address **172.30.42.130** and connectivity was verified through network testing.
